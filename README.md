# Student Management System (C)

This project is a simple Student Management System developed using C programming.

## Features
- Add student records
- View student details
- Update student information
- Delete student records
- File handling using .dat file

## Technologies Used
- C Programming
- File Handling

## How to Run
1. Compile the program:
   gcc student.c
2. Run the executable:
   ./a.out

## Description
This project demonstrates the use of structures, file handling, and basic CRUD operations in C.
